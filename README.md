🤖 Introducción al Aprendizaje Automático para Visión por Computador
¡Bienvenido/a al repositorio oficial del curso! Este espacio contiene todo el material práctico, código fuente, ejercicios y conjuntos de datos necesarios para realizar el curso paso a paso.

📌 Sobre el curso
Este curso está diseñado para enseñarte los fundamentos del Aprendizaje Automático (Machine Learning) aplicados al campo de la Visión por Computador. Aprenderás desde la manipulación y exploración de datos hasta la creación de modelos capaces de procesar, analizar y clasificar imágenes.
